# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | lists the files and directories in the current working directory |
|     cd directory_name       | changes directory to './directory_name' |
|     cd ..                   | changes directory to the parent directory of the current directory |
|     cd -                    | changes directory to the previous working directory |
|     mkdir directory_name    | creates (makes) a directory in the current directory called 'directory_name' |
|     touch filename          | creates a file with empty contents in the current directory called 'filename' |
|     git status              | gets the current state of git, like what changes are staged, out of date, etc |
|     git add -A              | stages all files |
|     git commit -m ""        | commit all currently staged files with an empty commit message |
|     git push                | pushes local commits to a remote such as github |
|     git pull                | pulls remote commits to the local repository |
